<h1>Santara Hotel</h1>
Manajemen sistem untuk penginapan dalam mengurus pemrosesan data kamar, customer, dan ekonomi perusahaan.
<br> <br>
Aplikasi ini digunakan dalam skala satu penginapan satu aplikasi yang dapat memudahkan customer dalam memesan kamar, memudahkan administrator dalam pengelolaan data, dan meningkatkan keamanan dan keandalan sistem penginapan.
